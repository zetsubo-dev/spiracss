Changelog

All notable changes to SpiraCSS packages are documented here.

0.5.0

The component root default changes to scope-explicit. Existing projects can set generator.scssRootStyle: 'class' to retain previous root generation and root syntax lint behavior without rewriting CSS. Child-file scopes are prohibited for all settings and require manual migration. HTML lint is unchanged. Comment Links has no functional change and is version-aligned with the release.

  • Stylelint: recognize @scope component roots and optional :scope / & references across the existing structural and ownership checks, without changing CSS output or specificity.
  • Stylelint: require scope for component roots when configured for scope; reject every @scope in configured child Block directories, support container/layer wrappers, and explain the Sass risk and class-form repair without moving the root include or changing generated child specificity.
  • Stylelint: reject ambiguous nested scope ownership, prioritize explicitly configured component paths over the legacy assets/css exclusion, and classify child directories independently of component alias order.
  • HTML CLI and HTML-to-SCSS extension: add shared generator.scssRootStyle selection (class, scope, scope-explicit), defaulting new component root SCSS to scope-explicit. Block files loaded by meta.load-css() and selection-mode output retain class selectors; existing files are not converted.
  • Document the new forms, unchanged HTML rules, and Sass leading-combinator compatibility.
  • Update the English/Japanese CLI and VS Code tool guides, conversion examples, and diagnostic-first AI routing for the 0.5.0 root syntax.
  • Recommend scope-explicit for scoped SCSS compiled with Sass, while retaining optional direct scope syntax and avoiding automatic specificity-changing conversions.
  • VS Code extensions: exclude verification logs and compiled tests from the distributed VSIX packages.

0.4.0-beta

@spiracss/stylelint-plugin

Breaking Changes

  • Stylelint v17 required: Dropped Stylelint v16 support. Users on v16 should pin @spiracss/stylelint-plugin@0.3.x.
  • ESM only: Dropped CommonJS build. The package now ships ESM only.
  • Node.js >= 20.19.0: Minimum Node.js version raised to match Stylelint 17.
  • moduleResolution: TypeScript moduleResolution must be Bundler, Node16, or NodeNext (Stylelint 17 uses exports for type declarations).
  • createRules() accepts config object only: createRules(path) no longer accepts a file path string. Import spiracss.config.js and pass the config object directly, or use createRulesAsync(path) for path-based loading.

Changed

  • Simplified helpers.ts: removed CJS compatibility code (~80 lines), loadConfigFromPathAsync now uses native import() directly.
  • Removed CJS build scripts and tsconfig.build.cjs.json.
  • Build scripts converted from .cjs to .mjs.

0.3.0-beta

@spiracss/stylelint-plugin

Breaking Changes

  • Stylelint config restructured: stylelint.classStructure replaced by stylelint.base / stylelint.class, plus new per-rule sections (stylelint.placement, stylelint.pageLayer, stylelint.interactionProps, stylelint.keyframes, stylelint.pseudo, stylelint.rel).
  • Section renames: interactionProperties → interactionProps, keyframesNaming → keyframes, pseudoNesting → pseudo, relComments → rel.
  • Comment/cache keys renamed: stylelint.sectionCommentPatterns → stylelint.base.comments, stylelint.cacheSizes → stylelint.base.cache, sharedCommentPattern / interactionCommentPattern → comments.shared / comments.interaction.
  • External allowlist moved: allowExternalClasses / allowExternalPrefixes → external.classes / external.prefixes.
  • New rules enabled by default: spiracss/property-placement, spiracss/page-layer.

Added

  • New rule: spiracss/page-layer — Validates page-layer SCSS (component link comments required for child Blocks)
  • New rule: spiracss/property-placement — Validates property placement (container/item/internal) based on selector role
  • stylelint.pseudo.enabled option

Changed

  • Improved selector parsing and validation logic
  • Error messages updated for clarity
  • Better support for selectorPolicy (data/class mode)

@spiracss/html-cli

Breaking Changes

  • Config schema aligned with the new stylelint config: naming/external settings now read from stylelint.base / stylelint.class (old stylelint.classStructure keys removed).
  • External allowlist renamed to external.classes / external.prefixes.

Changed

  • HTML lint and SCSS generation now use the new external option shape.
  • Config warnings now report the naming source.
