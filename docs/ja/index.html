SpiraCSS

No More Memorizing CSS Architecture.

構造で設計を守る。
フレームワークが変わっても、同じ SCSS。

仕組みを見るスターターを試す

CSS 設計は規約に頼りがちで、チームが大きくなるほど一貫性が崩れやすい。
SpiraCSS（スピラCSS）は、設計のルールを HTML の構造と Stylelint で検証できる形にする。

フレームワークが変わっても、同じ SCSS

標準 CSS の @scope を使えば、CSS Modules、Vue の scoped スタイル、Astro の自動スコープに合わせて SCSS を書き分ける必要がありません。
Astro・Next.js・Nuxt・Eleventy・Vite 向けのスターターは、すべて同じ SCSS をそのまま使っています。
スターターを見る

SpiraCSS は、@scope や @layer を必須としません。@scope を使うかどうかは、ルート書式の設定で選べます。
