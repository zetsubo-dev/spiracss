変更履歴

SpiraCSS パッケージの主な変更点をまとめています。

0.6.0

v0.6.0 は共通のソース検証を追加し、lint診断と生成indexのマージを修正します。以下のAPIと診断は0.5.1では利用できません。

  • HTML、WebC、JSX、TSX、Astro、Vueのソース検証をCLI、任意のESLint接続、VS Codeで共有します。JavaScript parser、Astro compilerのWASM asset、第三者ライセンス情報を同梱します。
  • AIの修正ループ向けに、元UTF-16範囲、理由、分岐条件、実効設定に基づく修復条件を追加します。元位置の根拠がない報告は位置を省略し、VS Codeでは波線を捏造せずOutputに表示します。
  • lintはソースの出現ごとに検査し、後続の未分類tokenを UNCLASSIFIED_CLASS_TOKEN として報告するため、新しい診断で既定生成が停止する場合があります。繰り返しクラスの集約は生成時だけ行い、許可入力の出力互換は維持します。
  • 既存同期APIを維持し、呼び出し単位のparser読み込み、同期ソースlint、明示的な --format、JSONのソース検査範囲と解析回数を追加します。範囲内の未知値はfailed、parserや設定の失敗はblockedとし、passだけを成功とします。
  • 対応する有限式を、束縛scope、分岐条件、host固有の属性合成順に従って評価し、lintと生成で共有します。代替展開前に除くのは影響がないと証明できるoptional class tokenだけで、ESLint設定のcache identityには命名RegExpのsourceとflagsを含めます。
  • standalone Astroでは公式同期TSX変換、Babel、source mapを使います。未解決のソース関係の周囲でも独立検証できる兄弟は検査しますが、不確実な祖先関係を断定したり文書を生成したりしません。
  • dataモードの設定済み動的ARIAには値の命名規則や真偽文字列への強制書換えを課さず、到達可能な既知selectorを生成します。未列挙箇所は coverage.generationUnenumeratedSites で別報告し、CLIとVS Code Outputには非ゼロ時だけ1行表示しますが、既存同期APIの生成ファイル配列に件数は追加しません。
  • 設定済みdata属性の動的値は未解決となり、公開済み0.5.1と結果が変わる場合があります。静的な有効値と無効値の命名検査は維持します。
  • 命名、所属、末端Block、HTML設計上のBlock深度無制限、SCSS scope方針は変更しません。検証対象はソースであり、component props転送、slot、描画後DOM、各言語の文法全体は含めません。
  • 診断に基づく最小修正を説明し、既存のStylelint selector-max-type: 0 をcomponent配置に限定して推奨します。pageとglobalの例外は維持します。
  • 70,000要素のAstro入力がSpiraCSSルール無効でも45秒を超えるhostの既知制約を記載します。standaloneの完走は巨大入力のhost対応を意味しません。hostのバージョンと検証境界を参照してください。
  • npmパッケージのNode.js要件を >=24.22.3 <25 とし、拡張の開発・パッケージ化も24.22.3に揃えます。全パッケージのバージョンを0.6.0に揃え、過去の0.5.1の要件とVS Code最低版は変更しません。Comment Linksの動作変更はありません。

保守修正

  • 公式サイトのAstroを7.4.7へ更新します。動的タグの属性注入と画像エンドポイントのパス検証の修正を含みます。

  • Stylelint：セレクタ解析失敗と展開上限の診断を、失敗した元ソースのRuleに結び付けます。同一セレクタの複数出現、行単位のdisable、祖先・scopeの位置を保持し、展開上限1,000は変更しません。

  • Stylelint：空値のリテラルなSassプロパティグループを、構造を検査する6ルールの解析失敗から除外します。宣言を検査する2ルールは、内部が未検査であることと、同じ所有ルール内で値を保って接頭辞付きプロパティへ展開する修正方法を示します。入れ子プロパティの展開は追加せず、値付きグループ、補間、空白表記の既存制限も維持します。

  • HTML CLI：関連するWebCの動的input typeと有限の属性オブジェクトを共通validatorへ渡します。最初の式解析はparserまたはhost wrapperが担当し、無関係なtype診断とtype式の解析は追加しません。

  • HTML CLI / HTML-to-SCSS：index.scss のマージでコメント、@forward、変数、インデントを保持します。同一URLのbareな @use は引用符・タブの違いで重複追加せず、追加が不要なら内容と更新時刻を変更しません。複数行、コメント内、as / with / 行末コメント付き、相対URLの解決は従来の範囲です。

  • 未使用の内部経路と冗長な書き込みガードを削除し、既存のセレクタ処理を共有します。公開APIと設定は変更しません。

0.5.0

コンポーネントルートのデフォルトを scope-explicit に変更します。既存プロジェクトで従来のルート生成・ルート書式の lint 挙動を維持する場合は、generator.scssRootStyle: 'class' を指定してください。子ファイル内の scope は全設定で禁止し、既存の子 scope は手動で移行します。CSS の自動変換と HTML lint の変更はありません。Comment Links は機能変更なしで公開バージョンを揃えます。

  • Stylelint：@scope のコンポーネントルートを既存の構造・所有関係の検査で認識します。:scope / & の参照は必須ではなく、CSS 出力と詳細度を変更しません。
  • Stylelint：scope 設定時はコンポーネントルートに scope を要求します。設定した子 Block ディレクトリ内のすべての @scope は禁止し、container / layer の囲みも扱います。診断には Sass のリスクとクラス形式への修正例を示し、ルートの include 位置と生成する子の詳細度は維持します。
  • Stylelint：入れ子 scope の所有関係が判定不能ならエラーにし、コンポーネント配置の明示設定を従来の assets/css 除外より優先します。コンポーネント alias の順序に依存しない子ディレクトリ判定も行います。
  • HTML CLI / HTML→SCSS 拡張：共通の generator.scssRootStyle 設定（class / scope / scope-explicit）を追加し、新規コンポーネントルート SCSS は scope-explicit をデフォルトとします。meta.load-css() で読み込む Block のファイルと selection mode の生成はクラス形式のままで、既存ファイルを自動変換しません。
  • 各書式、変更しない HTML ルール、Sass の先頭結合子に関する互換性を記載します。
  • 英日 CLI / VS Code のツール説明・変換例と、診断を起点に参照する AI 向けガイドも0.5.0 のルート書式に合わせて更新します。
  • Sass を通す SCSS の scope 書式は scope-explicit を推奨します。直接形式も選択・lint 検査でき、詳細度を変える自動変換は行いません。
  • VS Code 拡張：検証ログとコンパイル済みテストを、配布する VSIX から除外します。

0.4.0-beta

@spiracss/stylelint-plugin

破壊的変更

  • Stylelint v17 必須: Stylelint v16 サポートを廃止。v16 ユーザーは @spiracss/stylelint-plugin@0.3.x を使用してください。
  • ESM のみ: CommonJS ビルドを廃止。ESM のみ提供。
  • Node.js >= 20.19.0: Stylelint 17 に合わせて最低バージョンを引き上げ。

変更

  • helpers.ts を簡素化：CJS 互換コード（約 80 行）を削除、loadConfigFromPathAsync はネイティブ import() を直接使用。
  • CJS ビルドスクリプトと tsconfig.build.cjs.json を削除。
  • ビルドスクリプトを .cjs から .mjs に変換。

0.3.0-beta

@spiracss/stylelint-plugin

破壊的変更

  • Stylelint 設定の再構成: stylelint.classStructure を stylelint.base / stylelint.class に分離し、各ルール用のセクション（stylelint.placement, stylelint.pageLayer, stylelint.interactionProps, stylelint.keyframes, stylelint.pseudo, stylelint.rel）を追加。
  • セクション名の変更: interactionProperties → interactionProps, keyframesNaming → keyframes, pseudoNesting → pseudo, relComments → rel.
  • コメント/キャッシュ系のキー変更: stylelint.sectionCommentPatterns → stylelint.base.comments, stylelint.cacheSizes → stylelint.base.cache, sharedCommentPattern / interactionCommentPattern → comments.shared / comments.interaction.
  • 外部クラス許可の移動: allowExternalClasses / allowExternalPrefixes → external.classes / external.prefixes.
  • 新ルールをデフォルト有効化: spiracss/property-placement, spiracss/page-layer.

追加

  • 新規ルール: spiracss/page-layer — ページ層 SCSS の検証（子 Block にコンポーネントリンクコメント必須）
  • 新規ルール: spiracss/property-placement — セレクタの役割に基づくプロパティ配置の検証（container/item/internal）
  • stylelint.pseudo.enabled オプション

変更

  • セレクタ解析・検証ロジックの改善
  • エラーメッセージの明確化
  • selectorPolicy（data/class モード）のサポート改善

@spiracss/html-cli

破壊的変更

  • 新しい stylelint 設定に合わせて、命名・外部クラスの参照先を stylelint.base / stylelint.class に変更（旧 stylelint.classStructure のキーは非対応）。
  • 外部クラス許可の設定を external.classes / external.prefixes に変更。

変更

  • HTML 検証と SCSS 生成で新しい external 形式を使用。
  • 設定警告メッセージに命名の参照元を表示。
