spiracss/pseudo-nesting

疑似クラス / 疑似要素を & にネストして書くルールです。

v0.5.0 から、@scope 内の :scope をルート参照として認識し、それ自体に & を要求しません。それ以外の疑似クラスには既存ルールを適用します。:scope:hover は :hover のネスト違反として報告し、:scope { &:hover { ... } } は疑似クラスのネスト条件を満たします。別途 interaction のルールも適用されます。

目的

  • 構造と状態の境界を明確にする
  • セレクタの意図を読みやすくする

✅ 適切

❌ 不適切

理由

  • 疑似は対象セレクタの責務として読める形にするため
